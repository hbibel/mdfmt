# MD026 Heading Punctuation Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Implement the approved MD026 fix and remaining diagnostics as the first
milestone 5 rule batch.

Architecture: Derive raw ATX/setext text suffixes from parsed heading ranges.
Share findings between diagnostics and fix proposals. Authorize exact configured
heading edits separately from generic protected-region permissions. Validate
reflow against a baseline containing only authorized heading edits.

Tech Stack: Existing Rust toolchain and parser; pinned markdownlint development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`,
`docs/compatibility/baseline.md`, pinned `markdownlint/lib/md026.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must fix MD026 when enabled, removing the configured trailing punctuation
  according to upstream semantics.
- Must preserve inline links without conversion to reference links.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must be idempotent: formatting the result again produces identical output.
- Work on main without creating worktrees; commit the existing AGENTS.md edit too.
- Continue without approval interruptions, as explicitly requested.

## Review Focus

- Empty/punctuation-only headings and custom syntax characters may expose syntax;
  only rule-prescribed suffix edits are authorized (Task 1).
- Setext trailing spaces, multiple lines and nested container prefixes must not
  be mistaken for ATX closing markers (Task 1).
- Unicode, BOM and CRLF must retain byte-safe spans and UTF-16 diagnostics (Task 1).
- Interleaved suffix punctuation/whitespace and entity/emoji exceptions must
  settle in one pass without over-removal (Task 1).
- MD013 joins and heading edits must coexist without bypassing reflow validation
  or moving inline permission boundaries (Tasks 1–2).
