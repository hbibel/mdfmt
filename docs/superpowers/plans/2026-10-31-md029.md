# MD029 Conditional Ordered Numbering Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Diagnose configured ordered-list numbering and safely normalize later
markers while preserving rendered starts, code and container ownership.

Architecture: Read direct item prefixes per ordered list through the diagnostic
parser. Match pinned style inference, zero starts and alignment/padding decisions.
Propose numeric-span replacements only, retaining the original first marker;
validate whole-document semantic/source equivalence and settle before reflow.

Tech Stack: Existing Rust parser/edit/configuration pipeline and pinned oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, conditional MD029
classification in `docs/compatibility/rules.json`, pinned `lib/md029.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- First ordered markers determine rendered start values; a configured mismatch
  remains a finding instead of changing the document's rendered numbering.
- one_or_ordered inference uses the first two actual markers, including disabled
  references; first zero affects ordered starts even for explicit ordered style.
- Right alignment compares complete prefix end columns; zero-padding inference
  and raw numeric width must not be confused with numeric equality.
- Marker-width changes can reclassify continuation paragraphs, quotes or literal
  code; keep every code value/protected byte and container unchanged or withhold.
- Nested lists, lazy/empty items, directives and tab-expanded source must preserve
  direct ownership, original coordinates and final-output idempotence.
