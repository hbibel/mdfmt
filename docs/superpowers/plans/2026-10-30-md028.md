# MD028 Blockquote Blank Diagnostics Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Report configured blank lines between consecutive sibling blockquotes
without merging intentionally separate quotations.

Architecture: Traverse sibling blockquotes and inspect source gaps using their
enclosing container prefixes. Match pinned line-only findings while preserving
all source. Use the tab-expanded diagnostic adapter for uncertain container tabs.

Tech Stack: Existing Rust parser/configuration/diagnostic pipeline and pinned
development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, diagnostic-only MD028
classification in `docs/compatibility/rules.json`, pinned `lib/md028.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- Only consecutive sibling blockquotes qualify; text, comments or distinct list
  items must not be skipped as though they were invisible blank formatting.
- A physical `>` line can be a logical blank inside an enclosing quote while
  separating two nested quotes; distinguish enclosing and current quote prefixes.
- Multiple blank lines each get their own finding, but unrelated leading/trailing
  blanks and explicit empty quote lines within one quote do not.
- Tabs and Unicode whitespace must follow Markdown token boundaries rather than
  visual width or a general Unicode trim operation.
- After MD012 reduces a blank run, final diagnostics and line directives must
  refer to retained source lines without making MD028 an implicit merge fix.
