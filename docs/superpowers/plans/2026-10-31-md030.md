# MD030 Conditional List Spacing Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkboxes for tracking.

Goal: Diagnose list-marker padding and safely normalize it without changing list,
paragraph or literal-code ownership.

Architecture: Share the diagnostic-only corrected list parse introduced by MD029.
Read ordered/unordered direct item padding and list physical-line extent; match
pinned single/multi-line option selection. Propose padding edits, then require
the existing whole-document semantic/source validator. Unsafe continuation
reindentation remains withheld rather than inventing code transformations.

Tech Stack: Existing Rust source/parser/edit/configuration pipeline and pinned
markdownlint development oracle; no new runtime dependencies.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, MD030 inventory entry,
and pinned `tools/parser-oracle/node_modules/markdownlint/lib/md030.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue inline on main without worktrees or routine approval pauses.

## Review Focus

- Single versus multi-line is the entire list's physical extent, not each item's
  paragraph or its enabled siblings; disabled markers still affect classification.
- Empty items have no prefix-whitespace token; more than four spaces can expose
  only one source character as padding and leave literal code intact.
- Tabs are source characters for pinned column differences, not automatically
  four fixable spaces; no virtual-only edit spans or changes through uncertain tabs.
- Padding changes can reinterpret continuation/code/nested-list ownership even
  when marker starts and prose text look unchanged; withhold unsafe batches.
- MD029/MD027/reflow interactions and inline directives must settle in original
  coordinates without shifting disabled targets or causing second-pass changes.
