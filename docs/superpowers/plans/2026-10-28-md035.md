# MD035 Thematic Break Style Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Add MD035 configured/consistent thematic-break diagnostics and safe native
repairs, which pinned upstream diagnoses without supplying automatic fixes.

Architecture: Recognize thematic-break regions explicitly. Determine the global
expected raw style using pinned semantics, including disabled first breaks in
consistent-style selection. Replace only recognized marker source when the
configured style is itself a valid thematic break and a whole-document reparse
preserves the block tree and all unrelated protected content.

Tech Stack: Existing Rust parser/edit pipeline; pinned Node development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, MD035 safe repair
classification in `docs/compatibility/rules.json`, pinned `lib/md035.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must be idempotent: formatting the result again produces identical output.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- Setext underlines and front-matter delimiters are not thematic breaks.
- Consistent style is chosen from source order, including breaks suppressed by
  per-line directives; reporting and edits still respect those permissions.
- Explicit arbitrary strings are allowed by the schema but must not be injected
  as Markdown when they do not preserve a thematic-break node.
- Indentation, lists and blockquotes can make an otherwise valid marker style
  change the block tree; a candidate must pass contextual semantic validation.
- Interactions with blank-line repair, prose reflow and EOF insertion must settle
  without losing original-coordinate edit reporting or directive scope.

## Task 1: Native thematic-break styles and evidence

`docs/compatibility/md035.md`; modify parser metadata, edit composition/pipeline,

coordinates across earlier deletions and later stages rather than assume that
every pre-reflow edit is a deletion.
