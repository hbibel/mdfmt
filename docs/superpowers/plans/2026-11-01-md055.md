# MD055 Table Pipe Style Diagnostics Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Report configured table pipe style without rewriting table rows.

Architecture: Reuse source-positioned table snapshots, adding the physical
delimiter row to each ordered row sequence. Infer document-wide or per-table
styles from all rows, including disabled rows. Detect real unescaped edge pipes
and report source-backed leading/trailing ranges; never edit table source.

Tech Stack: Existing Rust source/parser/configuration pipeline and pinned oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, diagnostic-only MD055
inventory entry and pinned `lib/md055.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue inline on main without worktrees or routine approval pauses.

## Review Focus

- Consistent style is inferred once across document tables; per_table resets only
  at true table boundaries, and disabled rows still affect inference.
- The delimiter row participates alongside header/body rows; source prefix
  stripping must distinguish quote/list padding from actual leading pipes.
- Escaped edge pipes, backslash parity, inline-code pipes and empty rows follow
  source table tokenization, not rendered cells or naive trimmed last characters.
- Missing/unexpected leading/trailing ranges retain source whitespace and full
  scalars where pinned UTF-16 ranges would split an astral character.
- Recovered/nested tables, literals/math/HTML, directives, severity and final
  diagnostics must retain ownership and preserve every table byte.
