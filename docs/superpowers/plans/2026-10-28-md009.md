# MD009 Trailing Whitespace Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Add configured MD009 trailing-whitespace diagnostics and safe removals of
incidental whitespace without discarding hard breaks or protected source.

Architecture: Match pinned JavaScript trimEnd widths and MD009's paragraph,
inline-code, fenced/indented-code and list-line exceptions. Propose only enabled,
unprotected trailing-whitespace deletions that preserve the semantic parse.
Settle them before heading/blank-line repairs and reflow; retain active MD009
line-scoped directive targets during reflow.

Tech Stack: Existing Rust source/edit pipeline and pinned Node development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, MD009 conditional repair
classification in `docs/compatibility/rules.json`, pinned `lib/md009.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must be idempotent: formatting the result again produces identical output.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- Upstream removes all flagged trailing whitespace, including some hard breaks;
  native repairs must preserve breaks and report unresolved findings instead.
- Code exclusion skips fenced interiors but not delimiter lines; include-code
  diagnostics must not become permission to rewrite literal code.
- Strict mode treats paragraph continuation and multiline inline code specially;
  widths and diagnostic spans use source UTF-16, not display columns.
- `list_item_empty_lines` uses pinned token-line semantics, not an intuitive
  blanket rule for empty lines; prove behavior against runtime evidence.
- Reflow must not move a disabled source EOF suffix into a newly enabled MD009
  line and cause a second invocation to make another edit.
