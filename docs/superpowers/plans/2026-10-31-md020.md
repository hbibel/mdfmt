# MD020 Closed ATX Separator Diagnostics Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Report missing closed-ATX separators without creating headings or removing
literal trailing hashes.

Architecture: Match pinned physical-root-line source syntax with a Rust regex
using explicit ECMAScript whitespace. Share MD018's single diagnostic math-flow
parse and code/HTML/front-matter exclusions through `heading_spaces`. No separator
proposal stage, because insertion can change structure or literal heading text.

Tech Stack: Existing Rust regex/source/parser/configuration pipeline and pinned
markdownlint development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, MD020 conditional
inventory entry and pinned `lib/md020.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue inline on main without worktrees or routine approval pauses.

## Review Focus

- Right-only missing separators can make a trailing hash part of heading content;
  never remove literal content by silently making a closed heading.
- Escaped terminal hashes, single-character content and arbitrary prefix lengths
  require pinned source matching rather than native heading-node assumptions.
- Unicode whitespace must use ECMAScript semantics; source spans must remain
  scalar-safe even where pinned UTF-16 ranges split an astral character.
- Code, HTML flow, math flow and front matter exclude physical lines with actual
  container ownership; inline tags do not suppress whole-line diagnostics.
- Shared exclusion helpers must keep MD018 behavior and disabled-rule scaling;
  directives, final-output formatting and idempotence remain stable.
