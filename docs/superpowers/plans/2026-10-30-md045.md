# MD045 Missing Alt Text Diagnostics Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Report Markdown/HTML images lacking configured alternate-text requirements
without inventing descriptions or editing image/table/HTML source.

Architecture: Check parsed Markdown image labels and source-valid HTML image
tags. Match pinned attribute-presence and aria-hidden exceptions, preserving
source spans and original UTF-16 columns. Add diagnostics only.

Tech Stack: Existing Rust parser/configuration/diagnostic pipeline and pinned
development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, diagnostic-only MD045
classification in `docs/compatibility/rules.json`, pinned `lib/md045.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- Empty Markdown labels are distinct from whitespace-only labels and undefined
  image references; apply pinned token semantics rather than inventing quality tests.
- HTML empty `alt=""` is still a present attribute, while a valueless `alt` does
  not match pinned checking; preserve the raw attribute matcher semantics.
- Comments, code, scripts/styles and invalid lookalike tags must follow pinned
  HTML token boundaries, not a global regular-expression search for `<img`.
- Multiline Markdown images have line-only findings, whereas HTML tags report
  only their first physical line's source range; keep byte and UTF-16 spans valid.
- Case-insensitive HTML names and aria-hidden exceptions coexist with scoped
  directives, Unicode whitespace, nested containers and final-output positions.
