# MD042 Empty Link Diagnostics Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Report configured empty links without inventing destinations or rewriting
link/table source.

Architecture: Inspect parsed links and reference definitions with raw-source
destination semantics. Diagnose empty resources and literal hash placeholders;
preserve entity/escape spellings rather than treating every decoded hash alike.

Tech Stack: Existing Rust parser/configuration/diagnostic pipeline and pinned
development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, diagnostic-only MD042
classification in `docs/compatibility/rules.json`, pinned `lib/md042.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve inline links without conversion to reference links.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- Raw `#`, escaped `\\#` and `&#35;` destinations may decode alike but pinned
  MD042 does not necessarily report them alike.
- Full/collapsed/shortcut references need upstream-compatible label lookup and
  first-definition ownership; undefined references are not empty parsed links.
- Images and code that resemble links must not become link findings, while
  links inside tables still receive diagnostic-only checking.
- Multiline link labels can make upstream emit an invalid negative range and
  throw; native must not panic or fabricate an out-of-bounds source range.
- Multiple links, BOM/Unicode columns and scoped directives must retain exact
  source ownership and final-output diagnostic positions.
