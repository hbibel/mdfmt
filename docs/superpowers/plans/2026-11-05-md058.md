# MD058 Table Separator Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Diagnose missing blank separators around tables and add them only when
reparsing proves that table source and document structure remain unchanged.

Architecture: Reuse source-positioned recovered table snapshots. Test physical
neighbor lines using pinned comment/whitespace blank semantics, then propose
localized blank insertions with existing container prefixes. Validate proposals
against the original parsed structure and protected source; report unresolved
findings on final output.

Tech Stack: Existing Rust source/parser/edit/configuration pipeline and pinned oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, conditional MD058
inventory entry and pinned `lib/md058.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue inline on main without worktrees or routine approval pauses.

## Review Focus

- File boundaries and comment-only or partial-comment neighbors follow pinned
  blank-line semantics; visible content alongside comments is not blank.
- Quotes/lists require real container prefixes; inserting blanks must not change
  list looseness, table ownership or HTML interpretation.
- Native fast-path and HTML-boundary recovered tables retain complete original
  start/end lines; recovery fragments cannot create independent apparent tables.
- Directives and fix:false control insertions without suppressing remaining
  enabled diagnostics; overlapping separators must not be duplicated.
- BOM/CRLF/mixed terminators, Unicode context and no-final-newline source retain
  valid source ranges and converge after unrelated safe fixes and prose reflow.
