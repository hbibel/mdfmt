# MD024 Duplicate Heading Diagnostics Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Report duplicate headings using configured global or sibling-only history
without renaming content, changing anchors or guessing document hierarchy.

Architecture: Extract pinned raw heading text, excluding only direct HTML tokens.
Track all parsed headings in document order, including disabled reference lines;
apply diagnostic permissions separately. Scope sibling-only history by heading
levels, not Markdown container ancestry, as the pinned rule does.

Tech Stack: Existing Rust parser/configuration/diagnostic pipeline and pinned
development oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, diagnostic-only MD024
classification in `docs/compatibility/rules.json`, pinned `lib/md024.mjs` and
`helpers/micromark-helpers.cjs` heading helpers.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- Disabled reference headings still populate duplicate history and affect level
  transitions; suppress only their findings, not their influence on later lines.
- Sibling-only history resets when heading levels change, including skipped
  levels, and is not partitioned by quote/list container ancestry.
- Direct HTML is excluded from heading text, but HTML nested in raw emphasis,
  links/code/entities and significant internal spaces retain pinned spelling.
- Empty/multiline setext headings and BOM/Unicode contexts must keep valid
  line-only spans without inventing heading content or normalizing too broadly.
- MD026 can expose a duplicate by removing punctuation; final diagnostics must
  use the formatted heading history and final source positions.
