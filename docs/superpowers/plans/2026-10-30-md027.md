# MD027 Conditional Blockquote Spacing Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

Goal: Diagnose extra blockquote separator whitespace and delete it only when
quote/list/code ownership and protected source remain unchanged.

Architecture: Map pinned quote-adjacent line-prefix spans from source-aware
container parsing. Apply list_items exclusions and line permissions, then
semantically validate deletion batches and settle them with whitespace stages.

Tech Stack: Existing Rust parser/edit/configuration pipeline and pinned oracle.

Spec: `docs/superpowers/specs/2026-10-21-mdfmt-design.md`, conditional MD027
classification in `docs/compatibility/rules.json`, pinned `lib/md027.mjs`.

## Global Constraints

- Must respect the effective supported markdownlint configuration.
- Must preserve content and Markdown meaning rather than force an unsafe fix.
- Must preserve tables. Violations involving tables may remain unresolved.
- Must report remaining violations when the effective configuration flags them.
- Must be idempotent: formatting the result again produces identical output.
- Continue on main without worktrees or approval pauses, as requested.

## Review Focus

- The quote's optional single separator is not excess whitespace; tabs consumed
  partly by visual expansion must map back without deleting the wrong byte.
- Code-indented prefixes and fenced literal interiors do not share ordinary
  paragraph line-prefix semantics; diagnostics must follow pinned tokens.
- list_items:false excludes both a following list marker and prefixes inside
  list ownership; distinguish nested quotes from ordinary quote paragraphs.
- Removing continuation indentation can change list/code ownership even when a
  line looks like quote spacing; preserve source when semantic validation fails.
- MD009/MD010/MD023/MD048 and line directives must settle with original edit
  coordinates and final-output findings without second-pass changes.
