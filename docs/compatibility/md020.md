# MD020 closed ATX separator gaps

MD020 reports missing separators around closed-ATX content without inserting
spaces. Such insertion can create a heading or turn literal trailing hashes into
closing syntax. Those meaning-changing edits are withheld. Overall coverage is
partial; the reference is markdownlint 0.42.0's `lib/md020.mjs`.

## Behavior

Column-one source matching follows pinned opening hashes, left/right padding,
single/multi-character content, escaped terminal hashes, closing hashes and
trailing ECMAScript whitespace. It is not limited to valid native heading nodes
or six heading levels. Both missing sides yield one finding, not two.

Left-only, right-only and both-side findings use the pinned leading, trailing
or middle-ellipsized context, respectively. Diagnostic context and positions
count UTF-16 units, with original byte spans. Where a pinned range starts or ends
inside an astral character's surrogate pair, native includes the full scalar.
Right-side columns can consequently start one UTF-16 unit earlier, and the range
can be one unit longer.

MD018 and MD020 share physical code, HTML-flow, math-flow and front-matter
exclusions. Math uses an optional diagnostic parse per rule, only when enabled
candidates and `$$` exist; no per-math-block reparse occurs. Formatting
parsing and its existing preservation guard remain unchanged. Inline HTML does
not suppress whole-line checking. General parser equivalence is not claimed.
Generic HTML immediately after a list or quote can retain the old container for
only its opening line upstream. The shared helper distinguishes these generic
tags from block tags using a paragraph-interruption probe, then reparses the
remaining source as flow after the actual container continuation ends. Real code,
math and subsequent HTML exclusions are retained through their actual ends,
including blank lines within fences. Separator blanks reset HTML boundary
behavior while retaining container indentation context.

Aliases/tags, directives, severity and fix permissions are respected. Diagnostics
describe final formatted lines, so MD013 reflow can change which missing-space
rule applies without inserting heading separators or removing source content.

## Evidence

`tests/md020.rs` covers source matching, escaped hashes, Unicode whitespace and
ranges, flow exclusions, permissions, CLI modes, heading-spacing interactions
and final-output reflow stability. MD018's scaling regression covers the shared
exclusion helper.

```sh
mise exec -- cargo build
node tools/parser-oracle/md020.mjs
```

The oracle passes 417 pinned/native diagnostic and source-preservation cases;
162 upstream automatic-fix outputs differ because native preserves meaning.
Node is not a runtime dependency.
