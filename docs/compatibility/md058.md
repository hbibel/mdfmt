# MD058 blank separators around tables

MD058 adds missing table separators only when reparsing preserves block structure
and protected source. All table row bytes remain unchanged. Unsafe cases retain
configured findings. The reference is markdownlint 0.42.0's `lib/md058.mjs`;
overall built-in rule coverage remains partial.

## Behavior

Each actual table's physical preceding/following line is checked. File boundaries,
whitespace-only lines, quote-only lines and comment-only lines are blank under
the pinned helper's semantics. Partial comments are handled the same way as
upstream; visible text outside a comment is not blank. Code/math/HTML-owned text
is not promoted into tables. Shared snapshots retain recovered table boundaries.

Missing separators are reported at the first or last table line, with pinned
trimmed/truncated source context. Empty source-backed spans identify the physical
line rather than pretending the finding is an edit to a cell. Aliases, tags,
directives, severity and fix permissions apply on final output.

Separator insertions retain the preferred original newline and quote prefixes.
List-owned tables, uncertain syntax and candidates whose reparsed structure or
protected source differs remain unchanged. Edit batches are deduplicated and
validated together; an unsafe batch may withhold otherwise safe separators.
Missing final newlines are not invented by this rule. These limits are deliberate
preservation differences from upstream's unconditional insertion.
