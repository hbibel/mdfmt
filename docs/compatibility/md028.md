# MD028 blockquote blank diagnostics

MD028 reports blank lines between consecutive sibling blockquotes without
merging quotations. The compatibility reference is markdownlint 0.42.0's
`lib/md028.mjs`. This rule is diagnostic-only under the preservation contract;
overall built-in coverage remains partial.

## Behavior

Each blank line between consecutive sibling quotes receives a finding. Text,
comments, headings, thematic breaks and different list-item ownership interrupt
the sibling relationship. Explicit blank quote lines inside one quotation are
not treated as gaps between quotes.

For nested quotes, a physical `>` line can be logically blank but its prefix
interrupts the pinned rule's token scan; it is not reported as an MD028 gap.
List continuation indentation can be ignored without merging distinct items.
Only Markdown blank whitespace is accepted; general
Unicode whitespace is not interchangeable with ASCII spaces/tabs.

Aliases/tags, scoped directives, severity and fix permissions apply to each
individual finding line. Disabling fixes does not hide configured findings.

## Preservation and positions

MD028 alone never changes bytes in any CLI mode. Other enabled safe rules can
change blank runs, but MD028 reports only final-output gaps; it does not provide
implicit permission to join quotations. Line-only findings use empty spans at
physical line starts, with BOM-aware columns.

The tab-expanded parser is read-only and retains original bytes. Existing parser
limitations remain; full upstream parser parity is not claimed.

## Evidence

The development oracle passes 123 pinned/native cases for quote/list
ownership, intervening content, logical blanks, tabs/Unicode/BOM/CRLF, directives
and severity. Another 500 generated sibling/container/gap comparisons passed
locally. `tests/md028.rs` covers source preservation, configured findings,
CLI error/warning behavior and retained gap positions after MD012 repairs.

```sh
mise exec -- cargo build
node tools/parser-oracle/md028.mjs
```

Node is a development-only comparison tool, not a runtime dependency.
