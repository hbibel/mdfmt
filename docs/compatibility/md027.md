# MD027 blockquote separator spacing

MD027 diagnoses extra quote-adjacent prefix whitespace and conditionally deletes
it without changing container ownership or protected source. The compatibility
reference is markdownlint 0.42.0's `lib/md027.mjs`. Overall coverage remains partial.

## Behavior

The optional single separator after `>` is retained. Extra source line-prefix
whitespace is reported using original byte spans and UTF-16 columns/context.
Nested quotes and list padding are distinguished from ordinary quote paragraphs.
With `list_items: false`, prefixes belonging to a following list or existing list
ownership are excluded.

List continuation indentation is consumed only when the full original item
indentation fits; lazy continuation prefixes can still be findings. Indented
code is excluded. A fenced body can expose only the opener's relative indentation
as a prefix, with remaining whitespace retained as literal code. Closing-fence,
HTML-flow, inline-code continuation and table-delimiter whitespace have their
own pinned token exceptions.

Aliases/tags, directives, severity and fix permissions are respected. Active
line-scoped MD027 overrides prevent prose reflow from shifting their source
targets onto newly enabled lines.

## Preservation and upstream errors

Protected tables, headings, code and inline units are not permission to delete
meaningful source whitespace. Remaining candidates must pass whole-document
semantic/source validation; a failed batch is withheld. MD027 settles with
existing whitespace/heading stages before reflow, with original-coordinate edits
and second-pass stability.

The diagnostic tab-expanded parse maps spans back to original bytes. Repairs are
withheld for uncertain structural tabs. The shared guard checks optional quote
separator tabs and later physical quote-prefix lines, not just container-start
offsets, so unrelated rules cannot rewrite through those uncertain boundaries.

Pinned upstream can throw on an invalid zero-length range when a fenced prefix
consumes only virtual tab expansion. Native reports valid source-backed prefixes
and omits virtual-only spans; it does not invent a zero-width whitespace edit or
repeat the upstream runtime failure. Existing parser-extension limits remain;
full upstream parser parity is not claimed.

## Evidence

`tests/md027.rs` covers literal repairs, ownership/list options, token exceptions,
protected source, tabs/Unicode/BOM/CRLF, permissions, CLI behavior, active reflow
overrides, cross-rule edit reconstruction and shared tab-guard preservation.

```sh
mise exec -- cargo build
node tools/parser-oracle/md027.mjs
```

The development oracle passes 245 pinned/native diagnostic, ownership and
idempotence cases plus safe handling of three recorded upstream runtime errors.
There are 72 preserved upstream-fix differences. Another 500 generated diagnostic
comparisons passed locally. Node is not a runtime dependency.
