# MD023 heading indentation

MD023 diagnoses heading line prefixes and conditionally deletes indentation.
The compatibility reference is markdownlint 0.42.0's `lib/md023.mjs`; overall
built-in rule coverage remains partial.

## Behavior

Diagnostics distinguish indentation from container syntax. A quote's optional
separator and a list marker's padding are not heading indentation. Continuation
lines retain the indentation required by their enclosing list. Nested quote
prefixes can expose more than one repair, so deletions settle before reflow.
An empty list marker's trailing whitespace does not increase its continuation
indentation; default marker padding determines the heading's prefix instead.

For setext headings, the first text line supplies the heading's prefix finding;
the underline and later text lines are not independently normalized. Context is
the original physical line, truncated to the pinned UTF-16 context limit.
Byte spans and CLI columns refer to original text, excluding a leading BOM.

Rule aliases/tags, severity, directives and fix permissions are respected.
Disabled fixes retain both source and configured findings.

## Preservation

Repairs preserve heading text/level and container ownership. Whole-document
semantic validation compares heading source without initial indentation while
retaining exact protection for other syntax. Code, tables and metadata are not
edited. A failed semantic check withholds the remaining deletion batch.

The tab-expanded parse is diagnostic-only; mapped spans never turn uncertainty
into permission to rewrite tabbed containers. Unmodeled syntax also retains its
bytes, and configured unresolved findings remain visible. Full upstream parser
equivalence is not claimed.

MD023 settles with MD010, MD009 and existing heading deletions before reflow;
edits remain expressed in original coordinates, including composite rule origins.

## Evidence

`tests/md023.rs` covers root/quote/list prefixes, multiline setext boundaries,
Unicode/BOM/CRLF, permissions and cross-rule reconstruction/idempotence. CLI
tests cover stdout, check, write and disabled-fix warnings.

```sh
mise exec -- cargo build
node tools/parser-oracle/md023.mjs
```

The development-only oracle compares 171 pinned/native diagnostic and native
idempotence cases; 14 native outputs intentionally differ from upstream's
single-pass fix. Native can settle an additional quote prefix in one invocation,
or preserve source when literal boundaries are uncertain. A further 1000 generated
container-prefix diagnostic comparisons passed locally. Node is not a runtime
dependency.
