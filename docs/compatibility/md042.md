# MD042 empty link diagnostics

MD042 reports empty links without inventing destinations or changing source.
The compatibility reference is markdownlint 0.42.0's `lib/md042.mjs`. The rule
is diagnostic-only under the preservation contract; overall coverage is partial.

## Behavior

Inline links with empty destinations or raw literal `#` placeholders are reported.
Raw spelling matters: entity/escape forms that decode to `#` are not generally
equivalent for this rule. Angle-wrapped inline destinations are checked, whereas
the pinned reference-definition lookup considers only raw definition destinations.

Full, collapsed and shortcut references follow the pinned helper's first
normalized definition ownership, but the rule looks up the reference using its
raw trimmed label. This produces unintuitive case/internal-whitespace exceptions;
the native diagnostics retain those observed distinctions rather than imposing
an intuitive case-insensitive lookup on the rule.

Images, literal code and undefined references are not treated as empty links.
Links in tables are checked without modifying table source. Aliases/tags,
directives, severity and fix permissions apply normally. Disabling fixes does
not suppress remaining findings.

## Spans and upstream runtime failures

Findings use valid full-link byte spans and original UTF-16 columns, excluding
a leading BOM. Context normalizes line endings and follows the pinned truncation
limit. Other safe repairs run first, so findings refer to final output.

The pinned rule computes its range length by subtracting columns across lines.
For a label such as `[a\nb]()`, the resulting invalid range causes upstream to
throw instead of reporting the violation. The native rule deliberately reports
the empty link with a valid multiline source span; it does not reproduce the
throw or fabricate an out-of-bounds range.

The tab-expanded diagnostic parse remains read-only, with ranges mapped to
original bytes. Existing parser-extension limitations remain; full parser parity
is not claimed. MD042 alone never edits source in any CLI mode.

## Evidence

`tests/md042.rs` covers raw resources/references, duplicate definitions, escaped
labels and inline code, tables/images, Unicode/BOM/CRLF, multiline spans,
permissions, severity, CLI behavior and final positions after safe repairs.

```sh
mise exec -- cargo build
node tools/parser-oracle/md042.mjs
```

The development oracle passes 168 pinned/native comparisons and checks safe
native handling of six recorded upstream runtime-error cases. Original source
is preserved throughout. Errors are recorded separately, not presented as
successful upstream findings. Node is not a runtime dependency.
