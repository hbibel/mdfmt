# MD014 command-only shell prompts

MD014 diagnoses prompt-prefixed command-only code blocks while retaining code
bytes. Deleting prompt characters requires deciding whether they are literal
code or presentation, so the native rule does not apply upstream's automatic
deletion. Overall coverage is partial; the reference is markdownlint 0.42.0's
`lib/md014.mjs`.

## Behavior

Fenced and indented blocks are classified as a whole before line permissions.
Every nonempty code-value line must begin with optional ECMAScript whitespace,
then `$` and further whitespace. Any output/non-command value suppresses all
findings for that block, including output on a disabled line. Truly empty lines
do not participate; a whitespace-only code value does participate and suppresses
the block. Missing output is diagnosed without inventing it.

Source-positioned code snapshots retain fence/container-relative content, nested
quotes/lists, tabs, unclosed fences and original byte provenance. The shared
diagnostic literal parser also retains snapshots recovered after generic HTML
container boundaries. Inline code and math are not shell blocks. Formatting
parse options remain unchanged; general upstream parser parity is not claimed.

Findings span only `$` and its following whitespace using original bytes and
UTF-16 columns. Context retains code-value indentation and uses pinned truncation.
Aliases/tags, directives, warnings and fix permissions are respected. Final
diagnostics describe formatted output; this rule never edits code content.

## Evidence

`tests/md014.rs` covers whole-block classification, source-backed prompt ranges,
flow/inline exclusions, recovered root code, permissions, CLI modes and reflow
idempotence. The pinned corpus adds nested fence indentation and tab variations.

```sh
mise exec -- cargo build
node tools/parser-oracle/md014.mjs
```

The oracle passes 336 pinned/native diagnostic and source-preservation cases;
184 upstream automatic-fix outputs differ because native preserves code.
Node is not a runtime dependency.
