# MD033 HTML diagnostics

MD033 reports disallowed opening HTML tags under markdownlint 0.42.0's
`lib/md033.mjs`. It never removes or escapes HTML; tables remain unchanged.

## Behavior

- `allowed_elements` is case-insensitive. `table_allowed_elements` overrides it
  inside tables; omission inherits the ordinary list, but an explicit empty list
  allows no elements in tables.
- Closing tags, comments, declarations, autolinks, code and math are excluded
  according to the pinned parser. Processing instructions retain upstream's
  tag-name matcher (`<?php?>` reports `?php?`). This is not DOM validation.
- Non-comment HTML blocks are diagnostically reparsed as Markdown with HTML flow
  and indented code disabled. Apparent tags in script/style strings can be
  findings. Unterminated and malformed comments follow that same upstream
  boundary rather than suppressing the rest of a document.
- Resolved image descriptions, including nested images, are reparsed as inline
  content. Flattened line breaks cannot invent block or table ownership.
- Rule aliases/tags, inline directives, severity and effective line options
  apply normally. Disabling fixes does not suppress findings.

## Source positions and limits

The read-only diagnostic view excludes front matter, normalizes line endings,
expands diagnostic tabs and maps spans back to original UTF-8 bytes. Micromark
rules see raw comments, not markdownlint's separately sanitized markdown-it
input. Masking quotes inside comments would fabricate HTML tokens.

Findings cover the opening token's first physical line. Columns count original
UTF-16 units, excluding an initial BOM, and refer to final output after approved
repairs. No diagnostic parse authorizes edits. Existing parser-extension limits
remain; full upstream parser equivalence is not claimed.

## Evidence

`tests/md033.rs` covers 602 pinned observations plus literal allowance, range,
preservation, idempotence, CLI check/write/warning and final-position regressions.
The oracle compares both fix modes without changing input bytes:

```sh
mise exec -- cargo test --test md033
mise exec -- cargo build
node tools/parser-oracle/md033.mjs
```

Node is development-only, not a runtime dependency.
