# MD056 table-column counts

MD056 reports missing and extra table cells without adding, deleting or changing
table source. Such edits require author-owned content decisions. Overall rule
coverage remains partial; the reference is markdownlint 0.42.0's `lib/md056.mjs`.

## Behavior

Each parsed table's first row supplies its expected cell count, regardless of
whether that row's rule permission is disabled. Subsequent counts use actual GFM
cells, not rendered text or naive pipe splitting. Escaped pipes and unescaped
pipes inside code spans follow the table parser's source-cell boundaries. Counts
reset for separate tables. Non-table text is not reclassified to create findings.

Short rows point at the last source character; long rows span from the first
excess cell through the row end. Spans use original bytes and UTF-16 positions.
If upstream starts a final-character range inside an astral surrogate pair,
native includes the full scalar: the column moves one UTF-16 unit earlier and
the range grows by one unit rather than naming an invalid byte boundary.

Source-positioned table snapshots share code/math/HTML container recovery, with
remapped row and cell ranges for recovered root flow. Literal code and math are
not tables; HTML-owned tables are not promoted into root checking. Existing
native parser limits remain, and general parser parity is not claimed.
Recovery follows the complete active list/quote chain, retaining surviving
container and paragraph context when an inner quote ends. Only an active lazy
paragraph can trigger that HTML-boundary adaptation; completed code, headings
and empty containers cannot. Independent root paragraphs after blank separators
reset stale native table state so an earlier lazy fragment cannot hide a later
table.

Aliases/tags, directives, warnings and fix permissions are respected. Diagnostics
describe final output after prose formatting, while table bytes remain intact.

## Evidence

`tests/md056.rs` covers exact counts/ranges, per-table inference, escaped/code-span
pipes, Unicode/BOM/CRLF, recovery, permissions, CLI modes and reflow idempotence.

```sh
mise exec -- cargo build
node tools/parser-oracle/md056.mjs
```

The oracle passes 447 pinned/native diagnostic and table-source-preservation
cases. Node is not a runtime dependency.
