# MD047 final newline

MD047 diagnostics and safe EOF repairs are implemented natively against the
pinned markdownlint 0.42.0 rule and `isBlankLine` helper. Coverage remains
incomplete; see `rules.json` for implemented rules.

## Behavior

- Enabled by default. A nonblank final line without a newline is a finding.
- Matches upstream's whitespace, quote-marker and HTML-comment blank-line
  exceptions. Empty files and comment-only EOF do not need a newline.
- Adds the original source's nearest EOF line-ending convention, or LF when none
  exists, even if reflow removes that original newline.
  Does not remove extra final blank lines; those belong to MD012.
- Respects configuration, aliases/tags, severity, inline directives and fix
  permissions. Disabled fixes still report configured findings.
- Diagnoses the final source scalar, widening upstream's one-UTF-16-unit span
  when needed to avoid invalid UTF-8 coordinates. CLI columns exclude the BOM.
- Runs after stable heading fixes and reflow. Public edit spans still refer to
  original input, including an EOF insertion after a heading suffix deletion.
- Withholds reflow of paragraphs affected by an active line-scoped MD047 override;
  joining or wrapping them could change which source text the directive disables.

## Preservation boundary

The final newline is not inserted into unterminated fenced code, indented code,
raw HTML, metadata, tables or globally protected parser-extension documents.
Configured diagnostics remain. Closed HTML comments and clearly closed code
fences permit insertion after their protected source rather than inside it.
Ambiguous tab/container indentation around closing fences may remain unresolved.
Fully front-matter documents are excluded from diagnostics, matching upstream.

These are intentional restrictions: MD047 is not permission to alter literal
content or table rows. A successful run still does not establish full
markdownlint compliance.

## Evidence

`tests/md047.rs` covers literal expected outputs, preserved EOF regions, fake
closing fences, CRLF/CR, directives, severity, BOM/Unicode, combined-rule edits
and idempotence. It also checks disabled-fix findings against 126 recorded pinned
upstream observations. CLI coverage exercises stdout/check/write, warning/error
statuses and unresolved code EOF.

```sh
mise exec -- cargo build
node tools/parser-oracle/md047.mjs
```

The development oracle checks both disabled-fix diagnostics and native safe fixes;
literal-region differences are explicit. `--record` refreshes upstream evidence.
Node is not required to build or run mdfmt.
