# MD055 table pipe styles

MD055 reports configured edge-pipe styles without rewriting table rows. This
retains the project's table-source preservation boundary. Overall rule coverage
remains partial; the reference is markdownlint 0.42.0's `lib/md055.mjs`.

## Behavior

`consistent` infers one style across document tables, while `per_table` resets at
each actual table. Explicit `leading_and_trailing`, `leading_only`, `trailing_only`
and `no_leading_or_trailing` styles require the corresponding edges. Disabled
rows still participate in inference. Header, delimiter and body rows are checked
in original source order.

Escaped trailing pipes use source backslash parity; an unescaped pipe remains a
table divider even inside inline-code source. Empty rows retain their source
style. Nested and recovered tables share the existing table snapshots and actual
container ownership. Literals/math/HTML are not promoted into eligible tables.
Diagnostic parsing recovers table headers and body rows skipped by native flow
fast paths, including rows beginning with `e`, `i`, or inline code. Synthetic
prefixes exist only during diagnostic parsing; all ranges map back to original
source. Recovered table spans also protect these rows from prose reflow without
replacing the formatting AST.

Leading header/body ranges begin after row indentation; delimiter-row ranges
retain pinned row-start indentation after consuming only ancestor list/quote
prefixes. Trailing ranges name the final physical row character, including
trailing whitespace. These are diagnostic ranges, not proposed pipe edits.
The extracted `parse::ContainerPath` helper also retains existing HTML recovery
behavior and maps virtual tab prefixes to original source boundaries.

Spans use original bytes and UTF-16 positions. If a pinned one-unit edge range
splits an astral scalar, native includes that whole scalar. A trailing range can
therefore start one UTF-16 unit earlier and be one unit longer. Aliases/tags,
directives, severity and fix permissions are respected. Existing parser limits
remain; full upstream parser parity is not claimed.

## Evidence

`tests/md055.rs` covers inference, disabled references, delimiter indentation,
Unicode ranges, CLI modes, warnings, table preservation and reflow stability.

```sh
mise exec -- cargo build
node tools/parser-oracle/md055.mjs
```

The oracle passes 1,112 pinned/native diagnostic and table-source-preservation
cases, including 672 generated nested/container/edge-style comparisons. Node is
not a runtime dependency.
