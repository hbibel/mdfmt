# MD010 hard tabs

MD010 reports configured hard-tab runs and replaces them only when the result
preserves Markdown meaning. The compatibility reference is markdownlint 0.42.0's
`lib/md010.mjs`; overall built-in coverage remains partial.

## Behavior

- Each consecutive tab run produces one finding with an original-source byte
  span and UTF-16 column, excluding a leading BOM.
- `spaces_per_tab` defaults to 1. Replacement uses that fixed multiplier, not
  visual tab stops. Zero can remove tabs only if meaning remains unchanged.
- `code_blocks` and `ignore_code_languages` follow pinned source semantics.
  With a nonempty ignored-language list, fenced blocks are excluded only when
  their raw language matches case-insensitively or no language is present,
  even when `code_blocks` is false. Fenced delimiter lines remain checked.
  Only ASCII spaces/tabs separate the language; Unicode whitespace remains part
  of the raw token rather than silently matching a shorter ignored language.
- Inline/indented code exclusions follow inclusive upstream overlap boundaries;
  a tab immediately following inline code can therefore be exempt.
- Aliases, tags, directives, severity and fix permissions apply normally.

Diagnostics use the shared read-only tab-expanded parse, mapping code boundaries
back to original bytes. Quoted unterminated fences use physical container ends,
while ordinary root/list fences can include a virtual EOF line. Parser extension
limitations remain; full upstream parser equivalence is not claimed.

## Preservation and composition

Code, tables, headings, links and other protected syntax are not rewritten merely
because the configured rule reports tabs there. Uncertain tabbed container
prefixes and unmodeled syntax retain their bytes. A semantic reparse must accept
the remaining repair batch; otherwise that batch is withheld.

Replacement allocation is bounded by four times the source byte length plus
1 MiB, using checked arithmetic. Exceeding that budget withholds the repair
batch and leaves configured findings instead of truncating output.

MD010, MD009 and heading deletions settle together before prose reflow. This lets
MD009 remove incidental spaces created by tab expansion in the same invocation.
General stage composition reports nonoverlapping edits in original coordinates;
an edit changed by several stages has sorted `+`-joined rule IDs as its origin.
Net no-op edits are omitted.

## Evidence

`tests/md010.rs` covers fixed multipliers, protected source, huge multipliers,
Unicode/BOM/CRLF, permissions, source coordinates and cross-rule idempotence.
Composition unit tests cover overlapping replacements/deletions, EOF insertion,
Unicode/CRLF boundaries, malformed ranges, repeated composition and net no-ops.

```sh
mise exec -- cargo build
node tools/parser-oracle/md010.mjs
```

The development-only oracle compares 414 recorded pinned/native diagnostic and
idempotence cases. In that corpus 229 native outputs preserve source that
upstream fixes; literal tests establish protection and meaning-preservation
reasons. Node is not a runtime dependency.

MD027's shared guard extension preserves optional quote-separator tabs and tabs
on later physical quote lines too, accounting for seven additional preserved
outputs in this existing corpus.
