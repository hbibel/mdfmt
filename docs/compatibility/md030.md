# MD030 list-marker spacing

MD030 diagnoses marker padding and conditionally normalizes source whitespace
without changing list, continuation or code ownership. The reference is
markdownlint 0.42.0's `lib/md030.mjs`; overall built-in coverage remains partial.

## Behavior

`ul_single`, `ol_single`, `ul_multi` and `ol_multi` select padding for complete
ordered/unordered lists. A list is single-line only when its physical line count
equals its direct item count, excluding trailing separator blanks. Disabled
markers still affect that classification.
Empty markers have no padding-whitespace token. More than four spaces expose only
one source character as padding, leaving the rest available to literal code.
Tabs count as source characters for pinned column differences, not automatically
four fixable spaces. Findings span full prefixes using original bytes and UTF-16
columns; edits replace padding only.

Aliases/tags, inline directives, severity and fix permissions are respected.
Zero padding is rejected by the pinned declarative option schema even though the
upstream runtime accepts it. Positive values above four remain diagnostics but
are never allocated as replacement whitespace: they cannot remain ordinary
Markdown marker padding and may be arbitrarily large.

## Preservation and interactions

Every repair batch must pass unchanged whole-document semantic/source validation.
Cases requiring coordinated continuation reindentation can remain unresolved;
this batch does not rewrite literal code to satisfy padding. Protected source,
uncertain tabs and invalid list-interruption boundaries withhold edits.

MD029 and MD030 share diagnostic-only tab expansion and equal-width delimiter
masking for native parser interruption errors. An interrupting ordered marker
must be spelled exactly `1`, not a numerically equal zero-padded spelling.
Interruption state is carried through newly opened list/item containers too;
empty nested ordered or unordered markers cannot interrupt paragraph content.
The original source is never expanded or masked for output.

Padding settles before numbering, quote spacing and prose reflow. If MD013 is
active within a list and its single/multi padding settings differ, padding edits
are withheld to avoid reflow changing the applicable spacing option on a second
pass. Configured final-output findings remain available. Original-coordinate
edit composition and idempotence are regression-tested.

## Evidence

`tests/md030.rs` covers styles, complete-list classification, empty/tabbed/code
boundaries, schema limits, oversized options, directives, permissions, CLI modes,
cross-rule composition and reflow stability.

```sh
mise exec -- cargo build
node tools/parser-oracle/md030.mjs
```

The oracle passes 235 pinned/native diagnostic, ownership/code preservation and
idempotence cases, plus 47 schema rejections. There are 71 preserved upstream-fix
differences. Another 500 generated diagnostic comparisons passed locally. Node
is not a runtime dependency.
