# MD003 heading styles

MD003 reports all six configured styles and conditionally converts heading
syntax without changing heading levels or inline content. The pinned upstream
rule reports styles but supplies no fixes; conversion policy belongs to mdfmt.

## Behavior and limits

- Supported styles are `consistent`, `atx`, `atx_closed`, `setext`,
  `setext_with_atx` and `setext_with_atx_closed`. Disabled first headings still
  establish consistent style.
- Safe single-line headings can change outer syntax. New setext underlines use
  three characters and the local line terminator. Links, code and other protected
  inline source remain exact; reparsing must retain the complete document tree.
- Multiline setext headings, empty headings requiring setext, and level 3–6
  headings under pure setext remain unchanged with diagnostics.
- Native child ranges can omit literal hashes. Conversions require agreement
  with lexical source-caption boundaries; ambiguous headings remain unchanged.
  Safety validation also compares complete lexical captions before and after
  conversion instead of relying only on native AST equality.
- Context-sensitive conversions that would merge paragraphs, change list/code
  ownership, or retarget effective line directives remain unchanged. Creating
  new setext underline prefixes inside list items is conservatively deferred;
  safe conversions from existing list-owned setext to ATX are supported.
- Existing uncertain-container, HTML/math and directive preservation boundaries
  still prevent edits. Diagnostic recovery does not authorize edits.
- A rejected heading does not prevent independent safe heading conversions.
  The complete selected batch is checked again before application.

Aliases, severity, inline disabling, `fix: false`, CLI check/write behavior,
final-output diagnostics and original-coordinate edit composition are covered.

## Important interaction findings

Table separators must run before heading-style conversion: a missing table gap
can make ATX-to-setext unsafe until MD058 inserts that gap. A regression requires
both fixes to settle in the same invocation. Empty closed headings are emitted
with one separator, avoiding an MD021 repair on the next invocation.

## Evidence

The pinned markdownlint 0.42.0 oracle records 1,206 configurations/documents,
including nesting, metadata, math, HTML recovery, Unicode, line endings, disabled
reference headings and inline syntax. Native tests compare check-mode findings;
runtime comparisons check remaining findings on repaired output and repeated
formatting. Every runtime conversion also preserves upstream heading text and
levels, including generated literal-hash, escaped-hash, link/code and container
cases. Literal native tests assert approved conversions, unchanged unsafe input,
original edit ranges, MD026 interaction stability and CLI status.

```sh
mise exec -- cargo test --test md003
mise exec -- cargo build
node tools/parser-oracle/md003.mjs
```

These tests establish the recorded contract, not full upstream parser equivalence.
