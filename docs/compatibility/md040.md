# MD040 fenced code language diagnostics

MD040 checks fenced code info strings without inventing languages or removing
attributes. The compatibility reference is markdownlint 0.42.0's `lib/md040.mjs`.
This rule is diagnostic-only under the preservation contract; built-in coverage
as a whole remains partial.

## Behavior

- Missing info produces a finding with the opening fence as context.
- A nonempty `allowed_languages` list matches the raw language exactly,
  including case and entity spelling.
- `language_only: true` reports metadata following the language. A disallowed
  language and extra metadata produce separate findings on the same line.
- Only ASCII spaces/tabs delimit language and metadata. Unicode whitespace is
  part of the raw token, not permission to match a shorter language.
- Literal indented code is not treated as a fenced block. Root, quote, list and
  unterminated fenced blocks are checked on their opening line.
- Rule aliases/tags, directives, severity and fix permissions are respected.
  Disabling fixes does not suppress configured findings.

Diagnostics use empty spans at the final output line start for upstream's
line-only findings; an initial BOM is excluded from the reported column. Missing
language context uses the pinned UTF-16 truncation limit. Extra-info details
retain the full raw opening fence.

## Preservation and evidence

MD040 alone never changes source, in any CLI mode. The tab-expanded parse is
read-only, and original fence text supplies raw language, metadata and messages.
Existing parser-extension limitations remain; full upstream parity is not claimed.

The development oracle passes 266 pinned/native cases for options, case, entities,
Unicode whitespace, tabbed/nested containers, EOF, directives and severity.
`tests/md040.rs` covers source preservation, two findings on one line, CLI
error/warning behavior and final diagnostic positions after other safe repairs.

```sh
mise exec -- cargo build
node tools/parser-oracle/md040.mjs
```

Node is a development-only compatibility tool, not a runtime dependency.
